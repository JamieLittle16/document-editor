# UX Principles

## Familiar without fossilising the ribbon

A Word/ONLYOFFICE user should become productive immediately, but we do not preserve historical interaction problems for visual similarity.

## The document owns the centre

Panels are contextual and collapsible. No permanent chrome should steal space without delivering continuous value.

## One command, many surfaces

Toolbar, menu, command palette, keyboard shortcut, plugin and automation invoke the same command identity and validation path.

## Explain formatting

The inspector distinguishes:

- style-derived properties;
- inherited properties;
- direct/local overrides.

Users can remove an override, update a style from selection, find matching text and audit inconsistent formatting.

## Keyboard quality is first-class

Everything important is reachable without a pointer. Command palette search includes actions, headings, styles, comments, settings and recent documents.

## Never block interaction on background intelligence

Spelling, grammar, diagnostics, AI and indexing progressively enrich the document. They do not gate typing or scrolling.

## Progressive complexity

Common actions are immediately visible. Advanced options are discoverable rather than permanently occupying the interface.
